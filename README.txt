KAPDA REGISTER PWA PACKAGE

1. Upload ALL contents of this folder to a static HTTPS host (for example GitHub Pages).
2. Keep index.html, manifest.webmanifest, sw.js, and icons/ in the same structure.
3. Open the hosted HTTPS URL in Chrome on Android.
4. Chrome menu (three dots) > Install app / Add to Home screen.

Important:
- App records are saved locally in that browser/device, not in GitHub.
- The hosted app code/site is reachable by anyone with the URL unless you add access control.
- Do not upload your CSV backups or actual shop records into the hosting repository.
- Keep CSV backups separately. Clearing browser/site data or uninstalling can remove local records.
